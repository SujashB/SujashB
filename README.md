# Hi, I'm Sujash 👋

**Applied AI Engineer** at [Iconic Founders Group](https://iconicfounders.com), working on agentic AI, LLM systems, computer vision and robotics. I graduated from UC Davis in June 2026 (B.S. Computer Science, minor in Technology Management) and I'm based in the Bay Area.

### What I'm doing right now

- 🤖 **At work:** building multi-agent systems on a custom Claude harness. That means CRO and CMO advisor agents evaluated with LangSmith, scheduled agents that keep a $35M+ HubSpot pipeline clean, and a Neo4j knowledge graph that joins HubSpot, Asana and SharePoint into one retrieval layer.
- 🟣 **[Pette](https://github.com/SujashB/Pette):** an on-screen companion orb that runs entirely in the browser. Its brain, SOMA, reads a screen you choose to share, searches folders you let it index, and ranks what you might want to do next with a TensorFlow.js model. There's no server and no cloud AI. It started at SpeedHacks, and I'm now using it to experiment with world models.
- 🦾 **Robotics:** working through ROS 2 ([ROS2-Tutorial](https://github.com/SujashB/ROS2-Tutorial)) and generating MuJoCo simulation assets with convex decomposition.
- 📖 **[FirmInk](https://github.com/SujashB/FirmInk):** my fork of the CrossPoint e-reader firmware for Xteink devices, with better typography and lightweight reading stats.
- 🔬 **Reading the code of** LLM inference engines like vLLM and SGLang.
